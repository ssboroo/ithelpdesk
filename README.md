# Монгол IT Helpdesk — Windows desktop

Монгол цэстэй, интернэтгүй ажиллах техникийн үйлчилгээний программ.

## Installer татах

[Releases](https://github.com/ssboroo/ithelpdesk/releases/latest) дээрээс `ITHelpdesk-Setup-1.0.N.exe` татаж ажиллуулна. Python тусад нь суулгах шаардлагагүй. Хэрэглэгчийн эрхээр сууж Start цэсэнд нэмэгдэнэ. Desktop shortcut сонгож болно.

Installer нь Windows CI build амжилттай дууссаны дараа гарна. [Actions](https://github.com/ssboroo/ithelpdesk/actions) хэсэгт шалгалтын үр дүн, installer artifact байна. Build нь тест, цонхны smoke test, executable бүтээлт, silent install / launch / uninstall шалгалт гүйцэтгэнэ.

## Боломжууд

- Хүсэлт үүсгэх, засах, техникчид хуваарилах; 5 төлөв, 4 зэрэглэл.
- Төхөөрөмж, серийн дугаар, эзэмшигч, хэлтэс, үзүүлэлт, ашиглалтын төлөв.
- Төхөөрөмж болон хүсэлт тус бүрийн засварын түүх.
- Гүйцэтгэсэн ажил, минутыг ажил гүйцэтгэсэн техникчээр бүртгэх.
- Программ, суудлын тоо, суулгасан төхөөрөмж, нийлүүлэгч, хугацаа.
- 30 хоногийн дотор дуусах болон хэтэрсэн лицензийн сануулга; хугацаагүй лиценз.
- Хайлт, хүсэлтийн төлөвийн шүүлтүүр, Excel-д нээх UTF-8 CSV.
- Сонгосон хугацааны техникчийн тайлан: бүртгэгдсэн хүсэлт, шийдвэрлэсэн хүсэлт, ажлын минут.
- SQLite нөөц хуулбар. Программыг хаасан / дахин нээсэн ч бүртгэл хадгалагдана.

## Эхний хэрэглээ

1. Техникчид → Нэмэх.
2. Төхөөрөмжүүд → Нэмэх (давхардахгүй код өгнө).
3. Асуудлын хүсэлт → Нэмэх → төхөөрөмж, техникч сонгоно.
4. Мөрийг давхар дарж → Хийсэн ажил, минут бүртгэх.
5. Асуудлыг шийдвэрлээд хүсэлтийн төлөвийг шинэчилнэ.
6. Программ, лиценз хэсэгт YYYY-MM-DD огноогоор лиценз оруулна.
7. Ажлын тайлан → хугацаа сонгох → CSV татах.

## Өгөгдөл ба хүрээ

Өгөгдөл `%LOCALAPPDATA%\RainyHelpdesk\helpdesk.db` дотор хадгалагдана. Upgrade болон uninstall нь энэ санг устгахгүй. Тохиргоо → Нөөц хуулбар хадгалах үйлдлийг тогтмол ашиглана. Сэргээхдээ программыг бүрэн хааж, одоогийн санг тусад нь нөөцлөсний дараа `helpdesk.db`-г нөөц файлаар солино.

Энэ v1 нь **нэг компьютерийн ажлын орчин**. Олон компьютерийн бүртгэлийг нэг оператор удирдана. Олон хэрэглэгч зэрэг холбогдох LAN сервер, нэвтрэх эрх, endpoint agent, автомат inventory, имэйл сануулга ороогүй. SQLite файлыг сүлжээний share / sync хавтсанд тавьж зэрэг нээж болохгүй. Windows хэрэглэгчийн эрхээр өгөгдлийг хамгаална; сан шифрлэгдээгүй тул лицензийн нууц түлхүүр хадгалахгүй.

Лицензийн сануулга программ эхлэхэд, мөн нээлттэй байхад өдөр солигдоход гарна. Программ хаалттай үед сануулга ажиллахгүй. Тайлангийн шийдвэрлэсэн тоо нь одоогоор шийдвэрлэсэн/хаасан бөгөөд хаалтын огноо сонгосон хугацаанд багтсан хүсэлтүүд; дахин нээвэл хаалтын огноо цэвэрлэгдэнэ.

## Эх кодоос ажиллуулах

Python 3.12, Tkinter хэрэгтэй. Нэмэлт runtime dependency байхгүй.

```powershell
py -3 app.py
py -3 -m unittest discover -s tests -v
```

## Windows installer бүтээх

Windows x64, Python 3.12 болон [Inno Setup 6](https://jrsoftware.org/isdl.php) суулгана.

```powershell
powershell -ExecutionPolicy Bypass -File .\build-windows.ps1 -Version 1.0.0
```

Гаралт: `release/ITHelpdesk-Setup-1.0.0.exe`. PyInstaller Python/Tk-г хамт багцална. Installer суулгах, shortcut, uninstall дэмжинэ. Одоогоор code-signing сертификат холбогдоогүй. Windows build-ийг Windows runner дээр хийнэ; Linux орчноос Windows executable шууд гаргахгүй.
