# RAINY Remote

Монгол интерфэйстэй, өөрөө ажилладаг Windows x64 алсын тусламжийн программ. C# / .NET 8 WinForms клиент, TypeScript / Bun relay. RustDesk, AnyDesk, Python эсвэл тусдаа .NET runtime суулгахгүй.

[Installer болон portable татах](https://github.com/ssboroo/ithelpdesk/releases/latest)

## Хэрэглэх

1. Хоёр компьютерт хамгийн шинэ ижил хувилбар нээнэ. Setup эсвэл portable сонгож болно.
2. Программ серверт холбогдож 9 оронтой дугаар, 6 оронтой нэг удаагийн код авна.
3. Тусламж авах тал дугаар, кодоо техникчдээ өгнө. Техникч оруулаад «Холбогдох» дарна.
4. Эзэмшигчид дуу, taskbar flash болон Windows мэдэгдэл ирнэ. Мэдэгдэл эсвэл tray icon дээр дарахад хүсэлттэй үндсэн цонх сэргэнэ. Windows-ийн Do not disturb болон дууны тохиргооноос мэдэгдэл/дуу хамаарна.
5. Эзэмшигч гар/хулгана удирдуулах эсвэл зөвхөн дэлгэц харах эрх сонгоно.
6. **Хоёр тал 16 тэмдэгт кодоо утсаар харьцуулж батална.** Хоёр тал баталсны дараа дүрс дамжина. Код зөрвөл цуцална.
7. «Холболт салгах» эсвэл үндсэн программыг хаахад дүрс, удирдлага зогсоно. Бүтэн дэлгэцээс салгахад ердийн цонхны хүрээ сэргэнэ.

Зөвшөөрөл, баталгаажуулалт, тохиргоо болон алсын дэлгэц үндсэн нэг цонхонд ажиллана. Программыг дахин нээхэд нэмэлт instance үүсгэхгүй, нээлттэй цонхоо сэргээнэ. Хаахад бүрэн гарна; далд service, autostart, unattended access байхгүй.

## Дүрс ба удирдлага

- Primary monitor-ийг 1920×1080 хүрээнд харьцааг хадгалан багтаана. Portrait, ultrawide болон жижиг дэлгэцийн харьцааг сунгахгүй; шаардлагатай захын зайтай харагдана.
- Суурь JPEG-ийн дараа зөвхөн өөрчлөгдсөн **128px хэсгүүдийг** дамжуулна. Өөрчлөлтгүй зураг илгээхгүй. 10 секунд тутам, хэмжээ солигдоход эсвэл том өөрчлөлтөд бүтэн кадр илгээнэ.
- Нэг кадр хүрч харагдсан ACK иртэл дараагийн кадр барихгүй. Хуучин кадрын урт дараалал үүсгэхгүй. 12 секунд хариу ирэхгүй бол сессийг дуусгана.
- Дүрс задлах, хэсгүүдийг нийлүүлэх ажил background thread дээр. UI нь бэлэн bitmap-ийг солино.
- Windows cursor-ийг дүрсэнд оруулна. Хулганы хөдөлгөөний хамгийн сүүлийн байрлалыг дамжуулж, event бүрийг цувуулахгүй.
- Зөвшөөрсөн үед зүүн/баруун/дунд click, wheel, keyboard болон key-repeat дамжина. Фокус алдах, салгах үед дарсан товчнуудыг суллана.

| Горим | Дээд хэмжээ | JPEG чанар | Бүтэн кадрын төсөв |
|---|---|---|---|
| Ухаалаг, хурдан хариутай | 1920×1080 | 78 хүртэл | 240KB |
| Ухаалаг, 280ms-аас удаан | 1280×720 | 65 хүртэл | 140KB |
| Ухаалаг, 650ms-аас удаан | 960×540 | 52 хүртэл | 65KB |
| Өндөр чанар | 1920×1080 | 85 хүртэл | 450KB |
| Хурд чухал | 640×360 | 50 хүртэл | 45KB |

Хугацаа нь capture/encode, дамжуулалт, хүлээн авсан талын render болон ACK-ийн нийлбэр; ping дангаараа биш. Профайл 5 секундын cooldown-тай. Төсөв хүрэхгүй үед encoder чанар болон хэмжээг бууруулна. JPEG нь lossless биш. 20fps хүртэл боловч бодит хурд сүлжээ, RTT, CPU, дэлгэцийн өөрчлөлтөөс хамаарна; Монгол дахь хоёр физик төхөөрөмж дээрх latency-г CI орлохгүй.

## Цонх ба холболт

- Жижиг цонхонд үндсэн картууд нэг багана, босоо гүйлгэлттэй болно. Viewer toolbar мөр шилжинэ. Prompt-ууд цонхонд багтаж гүйлгэж харагдана.
- PerMonitorV2 DPI awareness ашиглаж, цонхыг тухайн дэлгэцийн ажиллах талбайд багтаана.
- Сүлжээ тасарвал 2–30 секундын өсөх завсартай серверт дахин холбогдоно. **Өмнөх удирдлагын сесс, зөвшөөрлийг автоматаар сэргээхгүй.** Шинэ хүсэлт шаардлагатай.
- Серверт дахин холбогдоход ID, сесс дуусахад PIN шинэчлэгдэнэ. Байнгын нууц үг хадгалахгүй.
- Stream protocol5 шаарддаг. Хуучин клиенттэй холбовол шинэчлэх тайлбартай салгана. Хоёр тал ижил шинэ хувилбар ашиглана.

## Хамгаалалт ба сервер

Анхдагч relay: `wss://rainy-remote-relay-production.up.railway.app/ws`, Railway RAINY REMOTE project, Сингапур, нэг replica.

- TLS дээр ephemeral ECDH P-256 → SHA256 key → AES-256-GCM payload.
- Session ID болон өсөх sequence нь authenticated additional data-д багтана. Replay болон өөр сессийн багцыг хориглоно.
- Relay public key дамжуулдаг тул кодыг бие даасан сувгаар харьцуулах шаардлагатай. Шалгалгүй баталбал key substitution-аас хамгаалах баталгаа байхгүй.
- Host consent, PIN attempt limit, 45 секунд хүсэлтийн timeout, payload/rate/backpressure limit бий. Relay зөвхөн хосолсон socket-уудыг холбоно.
- Дэлгэц, сессийн агуулгыг application log эсвэл дискэнд хадгалахгүй. Session key санах ойд байна.
- Relay restart хийхэд сессүүд сална; HA / autoscaling / account controls байхгүй. Дээд хязгаар 200 socket.

Программд хугацаа дуусах эсвэл сарын захиалгын түгжээ байхгүй. Серверийн хостинг, сүлжээний зардал тусдаа. Тохиргооноос өөрийн WSS серверийн хаяг сонгож болно. Локал тохиргоо `%LOCALAPPDATA%\RainyRemote3\server.txt`; ID/PIN/session key хадгалахгүй.

## Одоогийн хязгаар

Windows x64 клиент. Бүх OS, бүх драйвер болон бүх физик төхөөрөмж дээр туршсан гэсэн баталгаа биш.

Файл дамжуулах, clipboard, дуу дамжуулах, олон монитор сонгох, UAC / secure desktop / Ctrl+Alt+Del, hardware video codec, address book, unattended service хараахан хийгдээгүй. Программыг байгууллагын үндсэн remote access болгон зарлахын өмнө нэмэлт security audit болон бодит сүлжээний урт хугацааны туршилт шаардлагатай. AnyDesk-тэй ижил latency эсвэл огт гацахгүй гэсэн баталгаа байхгүй.

## Шалгалт ба бүтээх

CI нь live relay-ийн хослол, PIN/татгалзах, replay, session isolation, native capture/render, delta tile сэргээх/өгөгдөл багасах, удаан хэрэглэгчийн backpressure, keyboard injection болон хоёр GUI клиентийн зөвшөөрөл/дэлгэц/хулгана/мэдэгдэл/дахин холболтыг шалгана. 640×480, 800×600, 1024×768, 1366×768 layout болон жижиг viewer-ийн toolbar clipping-ийг шалгана. Мөн install, startup, uninstall, portable болон давхар instance шалгана. UI зураг нь тусгаарласан CI орчны screenshot бөгөөд artifact-д хадгалагдана.

Windows x64 + .NET 8 SDK + Inno Setup 6:

```powershell
powershell -ExecutionPolicy Bypass -File .\build-windows.ps1 -Version 3.0.0
```

`native/Client/BuildConfig.cs` нь анхдагч relay хаяг. `relay/index.ts` нь Railway Function-ийн source; repository push зөвхөн клиент installer бүтээнэ. Relay source update нь тусдаа deployment. Одоо суусан RustDesk болон өмнөх Helpdesk өгөгдөлд хандахгүй.
